CARA PAKAI (XAMPP)
1. Salin folder ini ke C:\xampp\htdocs\bibit-shop
2. Start Apache dan MySQL di XAMPP Control Panel
3. Buka http://localhost/phpmyadmin -> tab Import -> pilih database.sql -> Go
4. Edit config.php (nomor WA, nama toko, alamat, password admin, produk)
5. Taruh foto di assets/img/produk-1.jpg dan produk-2.jpg
6. Buka http://localhost/bibit-shop/  (admin: /admin.php)
